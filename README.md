# 💼 JobPortal

A simple **Online Job Portal** mini project built using **Java, MySQL, JDBC, HTML, CSS, and JavaScript**.

## 🚀 Features

### 👨‍💼 Job Seeker
- User registration and login
- Browse available jobs
- Search jobs
- Apply for jobs
- View submitted applications
- Track application status
- Personal dashboard

### 🏢 Recruiter
- Recruiter login
- Post new jobs
- View jobs
- Edit job details
- Delete job listings

### 🗄️ Database
- MySQL database
- JDBC connectivity
- User management
- Company management
- Job management
- Application management

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Java | Backend |
| JDBC | Database Connectivity |
| MySQL | Database |
| HTML | Structure |
| CSS | Styling |
| JavaScript | Frontend Interaction |
| IntelliJ IDEA | Development |
