## 📌 Overview

**JobPortal** is a web-based recruitment management system designed to connect **Job Seekers** with **Recruiters** through a centralized platform.

The application provides role-based functionality where job seekers can discover and apply for jobs, while recruiters can manage job listings through a dedicated interface.

The project demonstrates how a web application can be developed using **Core Java as the backend**, **JDBC for database communication**, and **MySQL for persistent data storage**, with a responsive frontend built using HTML, CSS and JavaScript.

---

# 🎯 Objectives

The main objectives of JobPortal are:

- Provide a centralized platform for job searching.
- Allow users to register and securely log in.
- Allow job seekers to search and apply for jobs.
- Maintain application records in MySQL.
- Allow recruiters to create and manage job postings.
- Provide job seekers with an application tracking dashboard.
- Demonstrate Java-to-MySQL integration using JDBC.
- Implement a complete frontend-backend-database workflow.
